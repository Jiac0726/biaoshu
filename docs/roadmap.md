- [ ] Word 模板映射：标题编号、样式、页眉页脚、分页

- [ ] 从证据到最终正文的可追溯审核表
- [ ] 与其他 Agent 宿主的 Skill 适配测试

## 安全与工程原则

- 真实客户投标材料默认本地；无明确授权不传云、不写到公共仓库。
- 自动任务优先在单独分支提交 PR，人工审查后合并。
- 只迁移通用业务方法，不复制 OpenBidKit 源码；若后续复用第三方实现，须先核实许可条件。
- 每项能力都要有可运行测试和明确的“已实现/未实现”边界。
