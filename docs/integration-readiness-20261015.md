## 本轮已修复并新增回归测试

1. **来源索引防伪**：`verify_evidence()` 检查原件 SHA 后重新解析字节，要求索引每个定位和文本块与实际解析结果一致；同时禁止将 DOCX 表格生成的 `列N：` 标记当成原件引文。
2. **本地调用防代理泄露**：OpenAI 兼容 HTTP 适配器明确使用空 `ProxyHandler({})`，禁止继承操作系统 `HTTP_PROXY` / `HTTPS_PROXY` 代理，避免将本地模型提示和 API Key 交给环境代理。远程使用同样改为直连，不支持依赖环境代理的工作流。
3. **AI 未批准草稿关闭绕过**：严格检查直接扫描正文里的待人工审核标记，即使审核 sidecar JSON 丢失仍拒绝通过；正式导出继续要求严格检查。
4. **合同工期值误判收紧**：跳过 `2小时内` 等边界表达、日历年和其它复合子工期；只有经过精确数值加单位解析的 verified fact 才作为等式基线，同时忽略 Markdown `~~~` 围栏示例。
